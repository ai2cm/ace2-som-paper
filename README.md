# ace2-som-paper

This repository contains the code for running reference SHiELD-SOM simulations, doing initial data processing, training ACE2-SOM and running inference experiments, and generating figures for the paper titled "ACE2-SOM: Coupling an ML atmospheric emulator to a slab ocean and learning the sensitivity of climate to changed CO<sub>2</sub>."  A link to the pre-print can be found [here](
https://doi.org/10.48550/arXiv.2412.04418).
